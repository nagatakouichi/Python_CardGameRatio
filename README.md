# CardGameRatio

CardGameRatioはカードゲームにおいて、当たりのカードを引ける確率を計算するプログラムです。

# 作成理由

カードゲームを遊ぶ中で、簡単に確率を計算できたらいいと思うことがあり、作成しました。

# アピールポイント

①細かく確率を求めることができる  
デッキの総枚数、当たりの枚数、めくる枚数を入力することで、めくった中に当たりが何枚入るかの確率を求めることが出来ます。  
例えば、カードゲームで最初の手札に欲しいカードの枚数を当たりの枚数に、最初の手札の枚数をめくる枚数にすることで、最初の手札に引ける確率を求められます。  

②複数回試行を行った場合の確率を求めることができる  
入力したデッキの総枚数、当たりの枚数、めくる枚数に加えて、目標となる当たり枚数とゲーム数（試行回数）を決めることで、複数回試行したときに何回目標の当たり枚数をめくれるかを求めることが出来ます。  
例えば、①で示したような最初の手札に引ける確率を求めたのち、複数回ゲームをした時に最初の手札に欲しいカードがある回数の期待値を求めることが出来ます。  

# 機能概要

①デッキから当たりのカードを引く確率の計算

・デッキの枚数  
・デッキ内の当たりの枚数  
・引く枚数  
を入力することで、  

・期待値（枚数）  
・x枚当たる確率(xは0～引く枚数)  
を求められます。

②①で作成したデッキを複数回使用したときに当たりを引ける確率の計算

①のデッキ、引く枚数をもとに、  
・ゲーム数（試行回数）  
・引きたい当たりの枚数  
を入力することで、  

・引きたい枚数の当たりを引けるゲーム数の期待値  
・引きたい枚数の当たりを引けるゲームがy回の確率(yは0～ゲーム数)  
を求められます。  

# 起動方法

①バージョン3.12.5以降のPythonをインストールする。  
②このページからプログラムをダウンロードして、解凍する。  
③コマンドプロンプトを開く。  
④ダウンロードしたプログラムの「main.py」ファイルがあるディレクトリに移動する。  
⑤コマンド「python main.py」を実行する。
